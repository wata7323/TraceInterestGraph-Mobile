# Trace Mobile

Trace Interest Graph のスマホ単独版です。

この公開リポジトリには画面を動かす静的ファイルだけが入っています。メモ本文、写真、位置情報、PC版の共有データ、AIキャッシュは含まれません。入力した内容はスマホのブラウザ内（IndexedDB）へ保存され、サーバーへ送信されません。

PCを使わない間の一時メモに利用できます。PC内のOllamaによるAIタグ整理とPC版への自動同期は、この版では利用できません。

`記録` 画面の `移行ファイルを書き出す` からスマホのメモを保存し、PC版の `移行ファイルを取り込む` で安全に統合できます。既存メモは削除・上書きせず、同じIDで内容が異なる場合は競合コピーとして両方を残します。
