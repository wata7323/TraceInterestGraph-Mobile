# Trace Mobile

Trace Interest Graph のスマホ単独版です。

この公開リポジトリには画面を動かす静的ファイルだけが入っています。メモ本文、写真、位置情報、PC版の共有データ、AIキャッシュは含まれません。入力した内容はまずスマホのブラウザ内（IndexedDB）へ保存されます。

PCを使わない間の一時メモに利用できます。PC内のOllamaによるAIタグ整理は、この版では利用できません。

## ワンタップ同期

初回だけ `記録` → `このスマホを設定` を押し、表示された20文字の接続コードをPC版へ一度入力します。以後はスマホで `同期する` を押すだけです。PC版は起動時と30秒ごとに確認し、新しいメモを自動で取り込みます。

メモと写真はスマホ内でAES-GCM暗号化され、Cloudflareには暗号文だけが保管されます。接続コードはCloudflareへ送りません。既存メモの削除・上書きはせず、同じ内容は飛ばし、内容が異なる同一IDだけ競合コピーとして両方残します。

移行ファイルの書き出し・取り込みも、クラウド同期が使えない場合の予備手段として残しています。
