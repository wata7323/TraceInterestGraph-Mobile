# Trace Mobile

Trace Interest Graph のスマホ単独版です。

この公開リポジトリには画面を動かす静的ファイルだけが入っています。メモ本文、写真、位置情報、PC版の共有データ、AIキャッシュは含まれません。入力した内容はまずスマホのブラウザ内（IndexedDB）へ保存されます。

PCを使わない間の一時メモに利用できます。Ollama自体はスマホで動きませんが、PCで計算したAIタグ・意味リンク・3D座標を暗号化同期して、PCと同じ立体マップを表示できます。

## ワンタップ同期

初回だけ `記録` → `このスマホを設定` を押し、表示された20文字の接続コードをPC版へ一度入力します。以後はスマホで `同期する` を押すだけです。PC版は起動時と2分ごとに確認し、新しいメモを自動で取り込みます。PCで整理した結果はスマホ版の起動時または次回同期時に戻ります。

メモ・写真・AIタグ・意味リンク・3D座標は端末内でAES-GCM暗号化され、Cloudflareには暗号文だけが保管されます。接続コードはCloudflareへ送りません。既存メモの削除・本文上書きはせず、同じ内容は飛ばし、内容が異なる同一IDだけ競合コピーとして両方残します。PCから戻るAI整理結果だけは、同じ本文に対する新しい分析として安全に更新します。

移行ファイルの書き出し・取り込みも、クラウド同期が使えない場合の予備手段として残しています。
